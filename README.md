cfr1907CLUJ Results APP

The cfr1907Results APP presents the FC CFR 1907 Cluj-Napoca football team all official football matches results from competitions organized by the Romanian Football Federation, Professional Football League and UEFA starting from the romanian football season of 2004-2005. This App is a useful application for all the fans of CFR1907Cluj team and football that want to know about the team recent performances .

cfr1907CLUJ Results APP use case :

1 User download application code files from github FC-CFR1907ClujNapoca-Application repository on local device 2 User drag and drop MainPageCFRapp code file to opened browser and press Enter 3 Application Main Page is displayed 4 User choose desired season card and click season button (Ex: choose card "2021-2022 SEASON" and click button "Click 21-22") 5 The chosen Season Results webpage displayed (Ex: "2020-2021 Season Results" page) 6 User click chosen competition button (Ex: "Liga I. 2020-2021" , "CUPA ROMÂNIEI 2020-2021" , "SUPERCUPA ROMÂNIEI 2021" , "UEFA CHAMPIONS LEAGUE 2020-2021" , "UEFA EUROPA LEAGUE 2020-2021") 7 The chosen competition table with show results buttons displayed (Ex: "Liga I. 2020-2021" table and "Show/Hide Main Round Results" , "Show/Hide Play-Off results" , "Show/Hide Relegated teams" , "Show/Hide Promoted teams" buttons) 8 User click chosen competition show/hide results button (Ex: "Liga I. 2020-2021" table and click on "Show/Hide Main Round Results" button) 9 Chosen competition round results displayed 10 User click show/hide results button to hide chosen competition round results 11 User click the previously chosen competition button to hide competition table 12 User click browser back arrow to redirect to Application Main Page
